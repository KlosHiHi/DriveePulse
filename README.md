# DriveePulse
Наш проект решает важную проблему - подбор оптимальной цены. Модель помогает как клиенту, так и водителю. Клиент при заказе выбирает наиболее оптимальную цену, а водитель в свою очередь может изменить цены, с учётом разных рисков. Для демонстрации используется web-приложение.
___
### 1. Запуск бэкенда
pip install pandas numpy scikit-learn fastapi uvicorn (Установка Python зависимостей)

python model_training.py (Обучение модели, если необходимо)

cd backend (переходим в папку с сервером)

python api.py (Запуск API сервера)

### 2. Запуск фронтенда (в другой консоле)
cd app (Переход в папку приложения)

npm install (Установка Node.js зависимостей)

npm run dev (Запуск в режиме разработки)

**Frontend доступен на:** `http://localhost:3000`
